Id bahasa memberi warna pada blok kode. Id itu tidak mengubah karakternya sama sekali; hanya memberi tahu highlighter cara membacanya. Kodenya sudah literal, jadi id-nya aman ditambah atau dihapus kapan saja.

## Aturannya

Taruh id tepat setelah pagar pembuka, di baris yang sama, tanpa spasi. Tambahkan baris baru, lalu kodenya, lalu pagar penutup. Id-nya satu kata; jangan taruh titik dua atau kata kedua setelahnya. Pagar penutupnya biarkan polos. Baris baru setelah id memulai baris kode pertama; tanpanya, id dan baris pertama menyatu.

Id tidak ditampilkan di hasilnya, dan tidak mengubah teks di dalam blok. Id hanya memilih aturan warnanya. Blok dengan satu baris kode tetap butuh kedua pagar.

## Tanpa id, tanpa warna

Pagar tanpa id tampil sebagai monospace polos. Id yang tidak dikenali highlighter juga begitu; bloknya tetap tampil, tapi teksnya tetap satu warna.

<Example
  source={"```\nconst total = price * quantity\n```"}
  caption="Tanpa id, bloknya tetap tampil; hanya tanpa warna."
/>

Polos adalah pilihan yang tepat untuk keluaran yang bukan kode: log, pesan error, atau stack trace. Warna bisa menambah kebisingan saat tidak ada sintaks yang perlu dibaca. Blok polos juga pilihan yang jujur saat bahasanya campuran atau tidak diketahui.

## Hanya di dalam pagar

Id hanya berarti di pagar pembuka. Setelah backtick inline, huruf yang sama sudah jadi bagian dari kodenya. Blok berpagar juga hanya punya satu bahasa dari awal sampai akhir; kamu tidak bisa berganti di tengah jalan. Pagar penutup tidak menerima id, dan id yang nyasar di sana bisa membuat bloknya tidak tertutup.

## Perhatikan

Spasi antara pagar dan id membuat id-nya jadi baris pertama blok. Tempelkan id ke pagarnya: nama bahasa itu milik pagar, bukan milik kodenya. Hal yang sama terjadi kalau kamu menaruh id di barisnya sendiri.
